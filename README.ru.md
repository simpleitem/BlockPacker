# Auto-Modpacker

*[English](README.md) · Русский*

Консольная программа для игроков Minecraft, сборщиков модпаков и админов серверов. Она сканирует локальную папку `mods`, определяет сторону (клиент/сервер), находит недостающие зависимости и конфликты, проверяет обновления на **Modrinth и CurseForge**, а также умеет искать, собирать и строить модпаки. Чистый Python без зависимостей, работает на Windows, Linux, macOS и в Termux.

## Зачем нужен и чем уникален

Обычная работа с модпаком — это прыжки между двумя сайтами, угадывание стороны мода, ручной поиск недостающих зависимостей и чистка дубликатов. Auto-Modpacker делает это в одном месте: читает каждый jar, парсит `mods.toml` / `fabric.mod.json`, определяет сторону (список Manual-Side-Mods → Modrinth → CurseForge), показывает недостающие required и optional зависимости, несовместимости, дубли modId и одинаковые файлы, проверяет обновления на обеих площадках. В том же скрипте остаётся Auto-Finder: единый поиск, массовый сбор аддонов, рекурсивная сборка модпака с экспортом `.mrpack` и импорт по ссылкам.

## Самые удобные функции

- **`run`**: главный скан. Раскладывает моды по Client / Server / Both / Unknown, затем показывает недостающие зависимости, конфликты, дубли и статистику. Снапшоты пишутся в `script_logs/`. Большинство локальных команд работает по последнему `run`.
- **`updates` / `install missing` / `update`**: проверка обновлений на Modrinth и CurseForge, скачивание недостающих обязательных зависимостей или центр обновления для переноса сборки на другую версию Minecraft (plan → stage → apply / export / rollback).
- **`aternos`**: прямые ссылки Modrinth и CurseForge (плюс поиск) по результатам последнего скана — удобно для Aternos.
- **`bulk` / `build`**: сторона Auto-Finder — берёт категорию или основной мод, находит аддоны (включая аддоны аддонов), сопоставляет один и тот же мод на двух сайтах по хешу файла, скачивает jar и экспортирует `.mrpack`.

## Как пользоваться

1. Установи Python 3, скачай `Auto-Modpacker.py` и запусти: `python Auto-Modpacker.py`.
2. Выбери язык (`ru` / `en`).
3. Для CurseForge получи бесплатный API-ключ на console.curseforge.com и сохрани командой `key <твой ключ>`. Без ключа сторона и обновления идут только через Modrinth. Ключ хранится локально в `CurseForgeApiKey_DO_NOT_SHARE.txt`.
4. Вводи команды после `>`. Пример: `run` сканирует сборку, `stats` даёт краткую сводку, `updates` показывает доступные обновления, `report` пишет `modpack_report.html`.

*Slug* — это конец ссылки на мод, например `sodium` в `https://modrinth.com/mod/sodium`.

## Второстепенные функции

- `explain <modid|имя>`: полная карточка одного мода (сторона, зависимости, обновления, внутренности jar).
- `version <mc> <loader>`: целевая версия Minecraft и загрузчик для updates и install.
- `scan`: эвристический скан риска (сетевые библиотеки, нативный код, встроенные exe, PowerShell).
- `disable` / `enable` / `rename` / `remove` / `export` / `clean`: безопасная работа с файлами модов.
- `logs`, `timeline`, `compare`, `buildcompare`: история и сравнение сканов и папок.
- Команды Auto-Finder: `search`, `show`, `save`, `saveall`, `addons`, `newaddons`, `importlink`, `modupdate`. Любую из них можно вызвать как `finder <команда>`.
- `help` покажет все команды, `exit` — выход.
